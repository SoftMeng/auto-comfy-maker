# 约束体系总览

本目录是项目的**约束单一来源**。CLAUDE.md 只引用、不重复内容。

## 文件清单

| 文件 | 职责 | 硬性工具 |
|------|------|----------|
| `naming.md` | 命名规范（Rust 惯用） | clippy::naming |
| `structure.md` | 目录结构与模块职责 | 路径校验脚本 |
| `format.md` | 格式化规范 | `cargo fmt --check` |
| `commit.md` | 提交信息格式 | commitlint / PR 模板 |
| `testing.md` | 测试覆盖与组织 | `cargo test` |
| `quality.md` | 质量门控 | clippy + test + fmt |

## 约束层级

- 🔒 **强制**：违反则拒绝合入（fmt 不通过、test 失败、commit 格式错误）。
- ⚠️ **软约束**：违反需在 PR 描述中说明理由，但不阻塞。
- ✅ **硬约束**：有工具强制执行，等同于强制约束。

## 优先级原则

> 工具可强制 → 用工具。
> 工具不可强制 → 用评审。
> 评审不可控 → 拆分职责到工具能感知的维度。

## 修订流程

修改约束前：
1. 新约束能否被工具（lint / test / CI）验证？否则拆分为可验证条款。
2. 是否与已有约束冲突？有冲突的以更具体的为准。
3. 是否影响 CLAUDE.md 中的引用？同步更新。
